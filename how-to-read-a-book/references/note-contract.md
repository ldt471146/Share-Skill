# 三个阅读技能共用的笔记约定

需要生成、更新或核对笔记时，先读 [笔记与练习](../rules/notes-and-practice.md) 的 F11、F12。F11 区分结构、概念和主题阅读笔记；F12 要求标记指向重要关系。下列可追溯格式与 AI 对话做法是应用约定，不是原书规定的统一模板。

笔记开头用简短说明记录作品或仓库、实际版本和已读范围。版本或页码未取得时照实说明，使用已有的章、节、段落、图表、文件或用户提供的片段标记。不要把目录、论文摘要或 README 的阅读记成全文或全库阅读。

按当前目的组织内容，通常保留：作品要解决的问题或整体线索，关键概念及其关系，作者的主张与理由，读者的理解、评价和疑问，以及下一处需要核对的材料。检视笔记以初步结构为主；文学可以围绕人物、情节、形象与阅读体验；跨文献笔记围绕同一问题的不同回答。研究和代码特有字段由各自流程补充，当前不适用的项目无需填空。

每项主要内容说明它属于哪一种：作者明确表达，基于文本的解释性推断，或读者评价。短引使用引号或引用块；意译用自己的话保留条件，不能加引号伪装原句。推断给出理由和支持材料；评价不能写成作者结论。自然语言足以区分时不强制贴标签。

为关键解释、结果和评价提供能回查的作品位置，紧邻相关内容或集中在清晰的来源表中。方法来源使用原书规则 ID，与作品证据分开；普通笔记不必逐句堆砌方法编号。论文的版本和图表编号、代码的提交和文件行号均由实际材料确认。

不确定项要写清是哪种情况：未读到或未取得材料；在已检查范围内没有报告；相关证据互相冲突；尚未理解某一步。未检查全文时不能断言全书或整篇论文未报告。没有提供用户自己的理解时，笔记署明是助手整理，用户掌握程度尚未检验。

更新笔记时，以新读材料解释修订原因，保留仍适用的已有内容。若只检查笔记而没有原文，只能检查内部关系和待核验处，不认证其忠实于作品。交付长度、层级、格式和文件位置随用户需求决定，不强制打卡、固定复习周期、考试或分数。
