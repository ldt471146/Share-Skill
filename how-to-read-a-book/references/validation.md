## 结构与原文核验

三个技能均通过 skill-creator 的 quick_validate.py。套件 [验证脚本](../scripts/validate_skill.py) 通过入口预算、同级依赖、链接、规则归属、可达性和跨模块调用环检查；主入口正文 29 行，科研入口 12 行，GitHub 入口 24 行。主入口有 9 条任务路由，套件共 11 个流程文件，详细规则按任务加载。

同一脚本使用本机留存的 424 页 PDF 核对来源 SHA-256 和全部 482 处短摘，并对照完整段落语料核对连续文字与段落哈希，均通过。源书及完整语料没有随套件发布。机器记录见 [verification-results.json](verification-results.json)。短摘匹配不能独自证明意译的语义等价。

验证器曾将历史审查中的 A29、A35 标题误计为重复规则位置；已将规则归属检查限定于活动入口、规则和流程，复核后通过。随后在隔离副本实际运行 7 项检查：完整结构可通过；缺少共享笔记、缺少子技能、跨模块循环调用、伪造短摘、未指定验证模式和重添已删除规则均产生对应失败状态。详见 [故障注入结果](validator-behavior-results.json)。

## 新增流程的实际试用

两名未参与对应模块编写的代理，从案例指定入口开始实际读取流程与规则，分别完成科研 4 例、GitHub 与普通笔记 5 例。主代理逐份读回回答，确认下列材料范围内无剩余实质问题。

| 案例 | 实际观察 |
| --- | --- |
| R01：仅摘要的科研笔记 | 保留作者声称与未读范围，未编造实验与复现结果。 |
| R02：不同评估协议的论文比较 | 正确转入科研模块，未把 91% 和 94% 直接变成方法排名。 |
| R03：条件收敛证明 | 保留独立同分布和有限方差条件，未外推分布漂移结论。 |
| R04：论文公式与代码差别 | 由科研主导并有界使用实现流程；保留预处理未知和静态推演性质。 |
| G01：README 与接口冲突 | 指出双方依据，给出标明未运行的教学示例。 |
| G02：Git 教程附全局配置脚本 | 按学习目标讲解，未执行安装或修改全局配置。 |
| G03：运行过却误解归一化 | 根据代码纠正误读；实际执行所给四行，区分本次结果与用户报告，并给出练习。 |
| N01：修订已有读书笔记 | 根据 P1–P2 修正越界推论，保留用户疑问并直接交付。 |
| N02：短诗读书笔记 | 按文学方式解释字句和体验，未强加论证或编造作者背景。 |

合成材料见 [案例](bundle-evaluation-cases.json)，完整交付与实际读取文件见 [回答记录](bundle-evaluation-responses.json)，主代理的逐项观察与局限见 [结果](bundle-evaluation-results.json)。G03 的执行记录保留代码、Python 版本、输入和输出，本机绝对路径在公开记录中以占位说明替换。

这些是有界试用，覆盖显式入口与套件内部选路；没有测量在全部已安装 skills 中的自动发现效果，也没有完成真实论文的全面审查、整库教学或论文结果复现。助手回答与实测片段均不能证明用户已经掌握。后续发现新问题时应增加对应材料并重测受影响流程。
